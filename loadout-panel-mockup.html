Mockup — Loadout inspector panel · 3 variants · drag items from the grid into the panel

New Loadout entry in the inspector rail. It opens pre-filled with what the save says is equipped ( green dot), lets you drag items from the inventory grid into slots to experiment ( gold dot = changed from save, with a Reset to save escape hatch), and shows the combined stats. While dragging, compatible slots glow and everything else dims. All three variants share that interaction model — they differ in how slots and stats divide the 390px panel.

A

Manifest list · everything in one scroll

BuildPlanner's slot-group DNA compressed to one column: Gear → Weapons → Belt → Statistics, top to bottom. Dense, familiar, and stats use the same tile rows as the Build Planner.

Recommendation

Variant B. The whole point of dragging gear into a loadout is watching the numbers respond — the pinned stat dock keeps weight/armor/protections on screen during every drag, which neither A (stats below the fold) nor C (stats on another tab) can do. The paper-doll arrangement also matches the game's own inventory screen, so slot meaning is instant. The "Full breakdown ▾" expander can reuse BuildPlanner's tile + breakdown rows for the deep dive.

If you'd rather ship something simpler first, A is the low-risk version of the same model and can evolve into B later (the slot/drag plumbing is identical — only the layout differs).

Shared mechanics in all variants: panel opens pre-filled from the save's equipped flags (green dots); drops mark slots as modified (gold dots) and arm "Reset to save"; while dragging, only compatible slots stay lit; clicking an empty slot falls back to a picker (same as BuildPlanner) so the feature works without drag-and-drop on touch devices.
